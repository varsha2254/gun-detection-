About

This project detects guns using a webcam and Python OpenCV. When a gun is detected, it shows a red box and displays "GUN DETECTED".

TECHNOLOGIES
Python
OpenCV
NumPy
Imutils
FILES
project.py
gun_cascade.xml
README.md
INSTALLATION
pip install opencv-python numpy imutils
RUN THE PROJECT
python project.py
HOW IT WORKS
Opens the webcam.
Captures video.
Checks each frame for a gun.
Draws a box when detected.
Displays GUN DETECTED.
